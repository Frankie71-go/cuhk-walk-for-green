# CUHK Walk for Green 攻略卡（通用共享版）

中大通打卡校园路线，一学期满 **40 分 → 5 个 PE 参与分**。本仓库是给 CUHK 同学用的通用版攻略卡，手机浏览器直接打开即可，无需安装。

## 怎么用

直接用手机浏览器打开 `walk-for-green-template.html`：

- **顺路打卡规划器（页面顶部）**：输入你常去的两个地点，自动列出沿途读卡机、所在楼层、实拍图、Google 地图与计分。
- **我的 40 分进度**：点 `+2 / +4 / +6` 累加，自动存在你手机本地。
- **课表 + 今天推荐**：填你每周「从 / 到」的读卡机，页面会按「今天星期几」推荐顺路打卡路线。
- **📋 示例行程（左下角悬浮窗）**：不占正文，通勤时随手看。
- **🌐 语言（右上角悬浮窗）**：切换 普通话 / 粤语 / English。
- **学长姐捷径投稿**：论坛式，按路线分类，可点赞 / 踩。

## 计分规则（官方）

按「相邻读卡机的路段」给分，不是计步。每天封顶 6 分；同一趟行程须 1 小时内拍起点 + 终点各一次。

10 个读卡机分 5 个区：

| 区 | 读卡机 |
|---|---|
| A 崇基 | YIA、FYB、PSC |
| B | HSHEB、LKSP |
| C | MMW、LSK |
| D | UMSO（大学保健医疗中心） |
| E 和声/伍宜孙 | LWS、WYS |

跨区一般 1–2 分；**同区两个读卡机互拍 = 0 分**；**唯一陷阱**：崇基(A) 直奔 和声/伍宜孙(E) = 0 分，须经一个中间读卡机（B/C/D 区任一）。

## 开启云端共享（可选）

默认投稿只存在你本机。想让所有同学看到彼此投稿，需部署一个后端：

1. 在 CloudBase（腾讯云开发）新建环境。
2. 把 `tips-backend/` 部署为云函数（HTTP 函数），拿到公网 URL。
3. 在卡片里开启「云端共享」并填入该 URL。

> 云函数代码已自带「首次调用自动建集合 `wfg_tips`」逻辑，无需手动建集合。详见 [`tips-backend/README.md`](tips-backend/README.md)。

> 维护者的个人版已预先填好共享后端地址、默认开启云端共享，同学直接打开即可看到彼此投稿；本仓库的通用模板则需自行部署后端后填入 URL。

## 隐私说明

- 进度、课表、规划器**仅存在你本机浏览器**（localStorage，按设备隔离，不与任何人共享，换设备/浏览器不自动同步）。
- 只有「学长姐捷径投稿」经后端共享；后端代码**不含任何密钥**，凭证只在部署者一侧。
- 本卡片不依赖飞书——CUHK 同学大多用 WhatsApp / 微信 / Telegram，无需额外装 app。
